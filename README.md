# ⏱️ Stopwatch Web Application

A Stopwatch web app built for **Prodigy InfoTech's Web Development Internship — Task 02**.

## 🔗 Live Demo
https://harshbitz.github.io/PRODIGY_WD_02/

## 📋 Features
- Start, Pause, Reset, and Lap functionality
- Live centisecond-accurate timing
- Animated circular progress ring
- Neumorphic (soft-UI) design
- Scrollable lap history

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript (Vanilla)

## 📂 Files
- `index.html` — page structure
- `style.css` — neumorphic styling & progress ring
- `script.js` — timing logic & lap tracking

## 🎯 What I Learned
Using real timestamps (`Date.now()`) instead of tick-counting to keep timing accurate even under browser lag, and animating an SVG circle's `stroke-dashoffset` for the progress ring.
